# 🚀 Video-Audio Downloader

A modern, responsive web application for downloading videos and audio from popular platforms like Instagram, Facebook, Twitter, and 1000+ other sites except YouTube. Built with Flask and yt-dlp.

## ✨ Features

### 🎯 Core Features
- **One-Click Download**: Simple interface - just paste URL and download
- **Dual Format Support**: Download as video (.MP4) or audio (.M4A/.WEBM)
- **No FFmpeg Required**: Uses native formats - works everywhere
- **Auto-Download**: Files automatically save to your device
- **Progress Tracking**: Real-time download progress with visual feedback

### 📱 User Experience
- **Responsive Design**: Works perfectly on phones, tablets, and desktops
- **Modern UI**: Clean, attractive interface with glass morphism effects
- **Fast Processing**: Optimized for quick downloads
- **Error Handling**: User-friendly error messages

### 🔧 Technical Features
- **Multi-Platform Support**: Instagram, Facebook, Twitter/X, TikTok, Vimeo, and 1000+ sites except Youtube
- **Background Processing**: Downloads run in separate threads
- **File Management**: Automatic cleanup and organization
- **RESTful API**: Well-structured backend endpoints
